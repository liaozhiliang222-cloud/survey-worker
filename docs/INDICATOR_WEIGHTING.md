# 满意度分层加权

## 使用入口

交叉表分析 → 导入样本 → 指标加权（可选）。支持 XLSX / CSV 系数文件，不要求提供总体满意度题，也不限于售后维度。

1. 导入权重文件，选择工作表、原表起止行、二级指标列、变量/题项列和系数列。
2. 核对题项匹配，修正空缺或建议匹配的字段；按需调整反向题、量表范围、阈值和缺失码。
3. 确认保存。系数在各二级维度内归一化；空值、负值、重复变量、缺失字段和全零维度不能保存。
4. 选择应用维度、样本筛选和可选的受访者权重，预览或导出。另存当前设置会创建新版本；原方案保留。
5. 可独立导出加权结果，也可在“生成全部题目表”导出中同时得到四张附表。

方案按当前浏览器的项目隔离保存，不是跨设备云同步。方案只保存映射、参数和模型结果，原始样本不变。切换样本后须重新核对字段。权重方案可编辑副本，或将新导入维度与当前选中维度合并；重名维度须先改名或移除。

## 回归生成权重

关键驱动分析 → 满意度分层加权：复用交叉分析样本，每维度独立选择Y和多个X，设置题目方向及缺失规则。使用含截距的 OLS（可选 WLS），对非标准化B归一化；输出样本量、R²、Beta、标准误、t、p和VIF。

负B、零方差、秩亏及不足的残差自由度不能直接生成计分权重。小样本或较高VIF会提示复核。模型不自动取绝对值、不按显著性删除题项。保存后权重固定，交叉分组不重跑回归。回归样本权重与表现汇总样本权重分别设置。

## 计算与导出

默认0–10分，净满意度为100×（9–10分人数−0–6分人数）/有效基数，7–8分中立。也可选择原始均值。

每个交叉人群先按各题自己的有效基数计算表现，再按指标权重汇总。整题无有效样本时移除该题权重并对剩余权重重标；全部无效显示空值。显示N_any、N_all、题项N范围和权重覆盖率。没有逐人综合分、二级间总分或显著性检验。

Excel附表：二级加权指标、三级指标表现、指标权重方案、指标模型诊断。导出采用当次当前设置；训练筛选、Y、回归权重等诊断保留在模型附表中。外部系数不虚构回归诊断。
