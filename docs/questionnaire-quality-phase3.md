# AI问卷第三批：路径预览、局部修订、版本差异与试访

本轮新增 `questionnaire-workflow.js`（纯逻辑）与 `questionnaire-review-ui.js`（界面），由实际问卷页面接入。保留前两批审查与导出规则，未修改模型选择或部署线上。

## 使用流程

1. 生成问卷后，在“预览、版本与试访”查看路径及资格原文依据。
2. 在修订范围选择整卷或指定题目。局部题号可填 `D2、F1A`；`D*` 表示所有D前缀题目，不依赖自然语言模块名称。
3. 每次成功生成/修订保存独立版本。差异按题号列出新增、删除、修改，并独立显示题序、说明及编程规则变化。恢复旧稿创建新版本，使用旧版的需求快照重新审查。
4. 试访记录绑定当前版本及路径，可记录完整完成/中断/甄别终止、分钟数、反馈题号和意见。误录可删除，反馈可带入修订输入框，仍由用户点击提交。
5. 下载标准UTF-8 JSON档案留存全部版本、需求快照及试访记录。当前为页面会话内历史，刷新或关闭会清除；本轮未实现档案重新导入、项目级持久化或多人协作。

## 保证和边界

- 局部响应必须是严格JSON补丁，只允许替换指定的现有题目；重复、漏题、范围外题号、嵌套题目、代码块和模块注入均拒绝。现有题号、非目标题块、说明与结构化规则保留；明确的路径/资格备注改变时拒绝，提示改用整卷修订。语义上的隐含影响仍需人工复核。
- 修订失败不追加假“修改结果”，不创建版本，保留原稿与输入要求。生成与修订按钮使用共享执行锁，避免重入；返回时还会核对版本是否变化。
- 路径预览展示公共前段、所选分支、公共返回段，排除其他分支；缺失/回跳/重叠/跨分支返回不生成误导性题序。没有结构化路径时明确显示“未验证的顺序预览”。这不是答题运行引擎，不执行答案级显示、终止或配额，也不判定受访者资格。
- 实测统计只使用同版本、同路径的完整完成记录，显示n、中位数、线性插值P75及排除数。少于5份提醒仅为初步参考，该阈值是界面提示，不是统计充分性标准。不同路径不混合，新版本不继承旧版试访时长；无法从总时长推断单题用时。无记录不编造分钟数。
- 版本和试访JSON仅在点击下载时导出；试访意见带入输入框后，只有用户提交修订才发送给现有模型接口。

## 验证

单元回归覆盖局部修订范围与原文保留、恶意/无效补丁、分支隔离、非法路径、版本不可变性、不同版本和路径的试访隔离、异常时长与分位数。浏览器回归覆盖生成与整卷修订、局部差异、恢复、失败保留、手机布局、试访反馈与JSON档案下载。AI请求均使用受控响应，不代表真实模型生成效果已验收。
