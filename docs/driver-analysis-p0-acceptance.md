## 已交付

- 本页上传或拖拽 SAV、XLSX、CSV、制表符文本，支持使用项目已有样本和粘贴数据。
- 导入后先预览样本；Excel 支持切换工作表。每行一位受访者，第一行为字段名。
- 自动识别数值、文本、日期、编号、明确的类别字段、无变化字段及缺失情况。
- 两步配置：检查数据 → 核对分析目标 Y 和影响因素 X；分别点击按钮打开目标单选、因素多选的专用选择窗。
- 默认展示按题意、字段类型、量表信息和有效覆盖率初筛的推荐候选。编号、文本、常量和不适用类别字段收起；低覆盖率及其他可用字段可以在“全部可用”中自行查找。
- 因素选择支持整行点击、题号/题目/选项标签搜索、按题组筛选批量添加、已选侧栏与逐项移除。取消专用选择窗不应用本次修改，确认后在配置卡片中汇总。
- 不依赖列顺序；一个 Y、多个 X，禁止同一字段同时作为两种角色。关闭弹窗保留普通模式选择草稿。
- SAV 原始数值用于模型，题目标签和值标签用于展示；保留系统缺失、离散缺失码及缺失区间。字段详情可查看完整值标签。
- 只根据本次所选变量及额外缺失码确定完整样本。显示总样本、有效样本和排除数量。
- 对样本不足、常量和完全共线模型阻止运行；对高缺失比例、样本相对偏少及 VIF > 10 提示核对。
- 普通驱动分析与满意度分层加权分为页签，共用本页数据。分层模型可调用同一变量弹窗，按原始 B 生成计分权重并携带样本应用到交叉分析。
- 配置或数据修改立即清除旧结果并禁用导出。PPT 请求尚未完成时修改变量，会取消过期结果下载。
- 项目切换清空本页数据/结果，旧项目的交叉分析样本不能自动复用到新项目；异步导入有序号保护。
- 生产构建保留运行时 SAV 解析器和许可证；Node 源码托管支持 MJS 的 JavaScript MIME 类型。更新了页面帮助说明和静态资源版本。

- 调整列顺序后，选择相同字段得到一致结果。
- 独立解析基准模型 Y = 4 + 2A − B 得到 R² = 1，标准化系数为 2/√5 和 −1/√5，相对重要性为 2/3 和 1/3。

## 当前支持范围

- 文件上限 20MB，每个数据表最多 500 万单元格，普通回归最多 100 个自变量。
- 文件选择入口支持 `.sav`、`.xlsx`、`.csv`、`.txt`；XLS、ZSAV 不在本期入口范围。
- 标准化系数绝对值占比继续用于普通驱动排序；分层加权继续使用非标准化 B。类别题的虚拟变量编码及更换重要性分解方法不在本期范围。
- 分层加权默认量表为 0–10，运行前需要按问卷核对。普通模式使用原始评分，需在导入前统一反向题方向。
- PPT 浏览器测试未调用线上 PPT 服务；真实文件结构由本地 Python 渲染器测试覆盖。

## 真实电商 SAV 的 NPS 识别修复（2026-10-16）

真实文件测试通过环境变量 `SURVEYKIT_DRIVER_REAL_SAV` 显式传入本机路径；没有复制或修改原始 SAV，也未将用户原始样本加入代码库。普通测试不提供该变量时跳过真实文件场景，其余合成数据测试照常执行。

## LMG 平台与实际体验权重（2026-10-16）

关键驱动页面改为精确 LMG：每个模型固定同一批完整样本，计算所有预测变量子集的 R²，再按所有进入顺序的平均增量分摊解释力。原始贡献合计模型 R²，归一化后组内权重合计 100%；标准化系数只用于显示方向。精确计算最多 12 个因素，在独立 Worker 中执行，支持进度和取消。

方法依据：CRAN relaimpo 的 calc.relimp 定义（https://search.r-project.org/CRAN/refmans/relaimpo/html/calc.relimp.html）。代码为独立实现，未复制该包源代码。使用正交已知解、显式变量顺序平均、列顺序/计分比例不变性、已知负向条件系数及独立 NumPy SVD 核验。

问卷方案明确命名为“电商 NPS 0525”，验证题号、二级评分题干、平台和体验值标签后才可应用。一次建立 36 个模型：四个平台各有平台基础、六项实际体验、会员服务知晓者及全部适用二级指标联合诊断。仅将所需评分及分组编码传入 Worker，质控、联系方式、回访意愿、标识及三级细项不入模。Q7 多选组重叠。Q49 在京东/抖音的问卷平台范围矛盾作为阻断原因。

跳题保留缺失，各模型只使用本组适用指标，不补 0，不随子模型改变完整样本。额外缺失码仍由用户明确指定。页面展示组内人数、完整 N、排除数、LMG 权重、权重 95% 自助区间、方向及 β 区间、建模样本均分、首位概率。系数区间跨 0 时显示“方向未明确”。组内占比不得拼接为统一 11 项权重。

正式组内权重的经验筛查条件：N≥max(100,20×因素数)、完整样本保留率≥80%、最大 VIF<5、10 次重复 5 折均成功且平均验证 R²≥0.20、训练与验证 R² 差≤0.15、最大 Cook 距离≤1、500 次自助抽样成功率≥90%且至少 200 次、各项权重 95% 区间宽度≤30 个百分点。规则在页面可查，不声称是普适样本量标准或外部有效性保证。首位概率低于 70% 另提示首位不稳定。

未通过的模型不发布权重：权重、区间与原始 LMG 贡献均为 null，界面按题目顺序展示诊断而非排名，没有权重图，PPT 导出禁用。Excel 仍包括样本、原因和诊断，失败模型的权重列为空。修改数据、变量、缺失码、计算范围或项目会终止 Worker 并清除结果；旧消息和在途 PPT 不会覆盖新配置。

真实 SAV：3600 人、475 字段。36 个模型中 25 个通过筛查，11 个不输出正式权重，包括四组售后、四组联合诊断、京东/抖音会员口径待核实及京东优惠组的强影响样本。四个平台基础模型均为 N=900。独立 NumPy 原始设计矩阵最小二乘核验全部 25 组：权重最大误差 1.45e-14，系数最大误差 2.48e-14；重放商城基础模型 500 次抽样及验证折，权重区间最大误差 5.89e-15。

验证入口：`npm run test:driver-analysis`（26 项核心用例）、`tests/e2e/driver-lmg.spec.js`、既有导入/变量/分层回归浏览器用例及生产构建/源码服务验收。真实文件须显式设置 `SURVEYKIT_DRIVER_REAL_SAV`。验收 JSON/Excel 位于 `.data/driver-lmg-20261016`，可交付复核文件位于工作区 `outputs/driver-lmg-20261016`。原始 SAV、问卷均未修改或提交到仓库。

同时修复开发服务监听 Chrome 下载临时文件时可能发生的 Windows EBUSY 崩溃；Vite 忽略测试产物和下载临时文件，不影响源码热更新。

最终验收：26 项核心测试通过；25 个开发浏览器场景完成验证（修复目标显示及异步测试等待后，相关 3 项定点复验通过）；最终生产包 8 项关键浏览器场景、源码 HTTP 服务 2 项场景通过。Excel 逐行核验 114 行正式权重与页面模型一致，67 行被拦截模型的权重及区间均为空。生产包静态资源完整，4296 本地页面及 Worker 请求均返回 200。

## 当前版本：默认 β 绝对值权重，保留 B 与 LMG 对照（2026-10-16，第二次迭代）

本节取代上一节“未通过筛查即隐藏所有权重”的发布逻辑。按用户确认，默认权重为 `|β_j| / Σ|β|`；保留带符号的非标准化 B、标准化 β、回归截距、系数正负和方向区间。B 由 `β × SD(Y) / SD(X)` 还原，B 的自助区间由每次重抽样重新估计的原始系数计算，不拿固定标准差转换 β 区间。β 系数权重与 LMG 在同一批组内完整样本计算，分别计算区间、首位概率和筛查状态。可以即时切换主权重口径，另一方法并列对照，无需重算。

问卷匹配后默认应用四个平台及六类实际体验、会员服务知晓者和联合诊断的 36 组方案。题目仍只使用问卷二级评分；各组使用适用的题目集合，跳题不补 0。联系方式、质控、标识、分组编码与三级细项不作为解释因素。会员题在京东/抖音的平台范围冲突继续明确标为口径待核实。

可估计模型即使未通过样本量、共线性、验证解释力或稳定性等经验筛查，仍显示点估计，标为“探索性结果”，同时列出限制。自助抽样不足至少 200 次或成功率低于 90% 时，不报告区间或首位概率。完全共线、无变化评分或样本少到无法估计时，权重保持空值，不伪造平均/零权重。页面及 Excel 都保留判定、原因、有效 N 和缺失排除数。探索性 PPT 导出载荷和文件名包含探索性标记，切换权重方法或修改配置会使旧的在途导出失效。

真实 SAV 验收结果：36 个模型中，35 个可估计；默认 β 权重口径下 14 个通过经验筛查、21 个为探索性结果。抖音联合诊断 N=10，其中有无变化评分，无法估计。LMG 对照有 25 个通过筛查。两种方法的筛查数量不同，主要因为其权重自助区间宽度不同，不能共享一个方法的稳定性判定。四个平台基础 N 均为 900；商城、天猫、京东、抖音售后 N 分别仍为 117、41、63、44。
