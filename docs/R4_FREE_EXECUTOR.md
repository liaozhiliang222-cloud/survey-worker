# R4：现有服务器执行数据任务

用户明确不新增 Workers 订阅。生产采用现有阿里云执行器，Cloudflare 保留页面、授权和 D1/R2 存储；解析、登记、交叉表导出及统计计算转至服务器。持久任务、幂等键、租约与原子发布契约保持一致。

服务器通过专用服务凭据调用限定存储方法，不开放任意 SQL，不依赖管理 API OAuth。对象传输走二进制流；源文件对象禁止经内部接口写入。Node 执行器只监听 loopback，经已有 HTTPS 代理访问。任务子进程与 Python PPT 渲染共用 flock，子进程终止后锁由系统释放。数据解析结果由服务器直接保存；未调度的 pending 文件会被扫描，超时 processing 文件进入可重试失败态。

验证：真实子进程→HTTP 存储通道覆盖未认证/越权拒绝、登记去重、交叉表与 Excel 字节、重复任务和取消；取消或租约过期后迟到的发布触发 CHECK(valid=1)，整个 batch 回滚，分析结果及提交审计均不增加。HTTP 调用超时不杀死持久任务，600 秒执行截止与 650 秒进程保护分开处理。

在实际阿里云以 512MB、0.8 核限制运行人工基准：10 万行 × 20 列 CSV 登记约 1.4 秒、交叉表约 1.25 秒，任务峰值约 213MB；2 万行 × 20 列 XLSX 登记/交叉表各约 1.7 秒，峰值约 187MB；同规模 SAV 峰值约 133MB。以上为人工样例，不承诺全部问卷和文件的同等性能。Python/Node 跨进程排队、杀进程释放锁测试通过。

部署按 RELEASE_PROCESS.md；真实线上链路与版本核对另记。现有 D1/R2 用量规则不变，此改造不新增订阅。
