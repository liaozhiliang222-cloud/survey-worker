# AI问卷第二批：需求覆盖与测量设计

本轮在第一批规则上增加需求—指标—适用人群—题号—分析用途映射。生成和修订两个入口共享规则；页面、Word、Markdown均保留核对结果。平台格式继续剥离内部编程规则及系统报告。

## 结构

在原有 `questionnaire-rules` 的 version 1 对象中追加 `measurements` 数组，保留旧稿兼容性。每项包含唯一 id、source（field 与逐字 quote）、metric、population、role（segmentation/profile/outcome）、questionIds、analysis。

系统核实来源引用与题号存在性：无题目为“缺失”，部分不存在为“部分覆盖”，引用不匹配为“依据待确认”，结构齐备为“待语义复核”。不会输出“完整覆盖”认证。缺少或空映射会明确提醒，不会阻止旧稿阅读或编辑；测量建议为 warning，原有资格与逻辑错误的导出阻断规则保持有效。

另外按需求文本触发八类独立专项核对：共同分群、阶段与放弃、真实烹饪场景、标签认知链、高鲜标准、时间基线、概念比较和价格敏感度，避免仅相信模型自行列出的映射。缺口展示具体指标名称。

## 测量改进

- 共同分群变量与背景画像分开，强调跨路径口径一致。
- 行为频次限定回忆周期，实际行为不限选后再问优先级。
- 停止者、失败尝试与最近一次烹饪事件进入设计规则。
- 标签知晓、客观理解、信任、选择影响分别测量。
- 时间比例基于实际分钟数；价格绑定规格、币种与购买单位。
- 多概念共同测量吸引力、相关性、独特性、可信度和购买意向。
- 价格预算不能代替敏感度；按研究场景选择阈值或价格点测量，不强制使用PSM。
- 去掉为凑数量而固定要求选项数和矩阵行数的提示。

## 验证与边界

新增规则测试覆盖缺失映射、假引用、无效题号、错误结构、测量缺口、正例、概念可比性与重复修订。浏览器测试覆盖显示、修订、导出及备用稿。

专项识别使用启发式文本模式，仅定位候选题和明显缺口，不证明题目之间的真实逻辑关系、量表端点一致性、分群变量有效性或需求语义完整性。系统不能识别所有行业自定义指标，研究负责人仍须逐项审阅映射和进行试访。测试中的模型输出为受控样例，不代表已验证真实模型生成效果。本轮未部署。
