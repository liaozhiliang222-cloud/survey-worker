# 交叉表 KANO / PSM 专项计算

在交叉表导入数据、识别字段后，“KANO / PSM 专项计算”显示匹配数量。展开可调整字段、添加多组模型或移除匹配。配置编辑器按需展开，避免大问卷首屏加载数万个字段选项。

点击“生成全部题目表”，保留普通交叉表，并按配置增加 `KANO系数`、`PSM累计百分比` 工作表，目录提供跳转。每个 Banner 条件均复用交叉表原始编码筛选，独立计算本组结果，无有效分母显示 —。专项计算按人数统计，不自动使用权重列，不套用普通列比例显著性检验。

## KANO

以同一受访者的功能正向/反向回答查 5×5 评价表，输出 A/O/M/I/R/Q 人数、占有效配对比例及最高频类别（并列保留）。配对 BASE 包含六类；系数分母只含 A+O+M+I。

- Better = (A+O)/(A+O+M+I)
- Worse = −(O+M)/(A+O+M+I)，范围 −1 到 0。
- 缺失或不能解码的任一回答，整对排除。
- 自动匹配要求字段配对规则和 KANO 回答标签证据。仅有数字时不猜编码方向，须手动配置 1=喜欢或 5=喜欢。明确回答文字优先，不按回答分布反推方向。
- 支持 `D1_1__1/__2`、单下划线、`_F/_D`、`_functional/_dysfunctional`，以及唯一功能名的正反题。歧义不自动配对，可手动指定。

评价矩阵与系数参考 [Berger 等，Kano’s Methods for Customer-Defined Quality (1993)](https://studylib.net/doc/13322921/c--q-m)。

## PSM

使用四个实际金额字段，不能把价格区间或选择编码当作金额。价格统一升序，各 Banner 共享同一价格网格；每组四条曲线共用有效样本分母。

- 太便宜、比较便宜：金额 ≥ 当前价格的比例（反向累计，含等号）。
- 比较贵、太贵：金额 ≤ 当前价格的比例（正向累计，含等号）。
- 默认排除缺失、非数值、非正金额和价格逆序样本，允许相邻阈值相等。可改为四问完整、保留顺序异常；异常数量在表内列示。
- 不填补、排序或修改受访者原始回答。本次不增加价格交点估计，独立 PSM 模块不变。

累计方向及完整性检查参考 [pricesensitivitymeter 官方说明](https://search.r-project.org/CRAN/refmans/pricesensitivitymeter/html/psm_analysis.html)。相等阈值允许保留是本工具的明确口径。
