# 聚类计算与交互验收（2026-09-08）

## 修复

- K-Means 权重字段贯通 UI、Worker 和核心。零、负、缺失权重先排除，再计算标准化、有效样本量和分群；ANOVA 总均值按有效观测及权重计算。
- 分类文本按类别检测缺失、常量和不平衡；TwoStep 的有序变量进入分类变量计算，不再静默遗漏。
- 层次聚类忽略堆中过期距离；Ward、重心、中位数递推使用平方距离，欧氏距离输出还原单位；禁止不兼容距离组合。导出保留原始对象距离矩阵。
- Russell-Rao 和 Rogers-Tanimoto 二元距离公式修正。实际为 WPGMA 的选项改名为等权平均联接法。
- TwoStep 固定群数不可达时明确报错；自动群数展示实际候选范围及预聚类/顺序敏感性。该方法仍为两阶段近似聚类，不宣称与 SPSS 完全等价。
- 层次聚类初始切割群数、后续切换、画像、项目保存及导出使用同一结果。
- 取消直接终止 Worker；领域错误不再重复触发主线程计算；群数诊断移到 Worker；运行时锁定配置，配置变化使旧结果失效。
- 修复 CSS 覆盖 hidden 导致其他算法参数及导出区意外显示；更新运行时资源与缓存版本。

## 验证

- `npm run test:cluster-analysis`：三类算法、质量检查、画像和导出，以及权重、有序变量、手算层次合并距离、过期队列、原始距离矩阵、不可达群数、二元距离回归。
- `node tests/cluster-simple-ui.cjs`：示例导入、无数据长表预览、搜索、高级参数折叠、标准化、运行与清空。
- `node tests/cluster-state-ui.cjs`：旧结果失效、后台群数诊断、4 群切换 2 群后的 CSV 一致性、忙碌 Worker 取消、配置锁定、错误不重复计算。
- `npm run check:syntax`、`npm run build`。

## 使用影响

修复涉及真实计算，旧权重/有序变量/层次聚类结果应重新运行，结果可能合理变化。原始数据不修改。自动群数属于辅助建议，业务解释和稳定性仍需结合研究目标判断。


## 多选组误识别修正
- 原规则仅匹配变量名后缀，将 DV3_1～DV3_5 连续变量误当成多选组，并在组勾选变化时强制改成二元类型。
- 现在同时核对题号和所有行的非缺失取值，仅将一致的选中/未选中编码作为候选。兼容带中文题干的字段名；连续值、量表值、空列不据名称强行归组。
- 批量选择只更新用途，不修改测量类型或原始值；明确空白仍按缺失策略处理。没有候选时隐藏该区域。
- 实际 SAV 验收：人群聚类数据-0908.sav，2000 行；DV3 五列均为连续类型，各 19 个缺失；识别 36 个二元选项候选组。
- 验证：cluster-analysis-smoke、cluster-multi-groups、cluster-multi-groups-ui（实际 SAV）、cluster-simple-ui、cluster-state-ui 通过；Vite build 通过。
