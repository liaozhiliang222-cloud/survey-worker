# 旧结果筛查与重算指引

仅使用可验证的运行版本、实际参数、来源数据和结果识别影响。没有运行版本或参数的历史结果标记“需复核”，不能判为“已确认错误”。

|筛查条件|初始状态|复核内容|
|---|---|---|
|旧版本 NPS/均值来源含空白、null、纯空格|需复核|缺失是否进入分母或被转换为 0；逐项比较有效 base|
|分类百分比含缺失作答/缺失分组或数值 0|需复核|有效配对分母、0 类别和等权结果|
|使用截尾参数|需复核|最终权重范围、均值 1、最终边际残差及收敛标记|
|清洗来源为 weighted 或来源链不完整|需复核|是否丢失权重；是否重新校准；不能直接复用旧权重|
|XLSX 来自旧导出且源单元格为纯空格|需复核|是否已落盘成 0；现有 XLSX 单独无法区分真实 0，需原始材料|
|缺少运行版本、源文件、分析参数|需复核/材料不足|保留未知项；不得推断错误或自动补参数|

步骤：

1. 只读导出项目/文件/数据集/工具结果/证据/成果 ID、来源关系、运行版本、参数和时间；记录源字节 SHA-256，保留旧导出。敏感材料保存在授权存储。
2. 建立复核表，记录 old_result_id、source_dataset_id、source_file_id、source_sha256、old_revision、完整参数、review_reason、review_status。缺失字段写 unknown。
3. 在修复候选的隔离复核项目中复制源材料重算，勿覆盖旧数据或结果。加权清洗必须回到 Raw/Clean，重放已确认清洗规则后重新加权，保留目标/截尾/迭代参数和最终诊断。
4. 记录 new_project_id、new_dataset_id、new_result_id、new_revision、source_sha256、参数、差值及新旧 base。数值对比使用相同题目、标签、分组、缺失与舍入口径；材料或口径不一致时仍为需复核。
5. 只有可复现差异和来源/版本证据完整时标记已确认影响；无差异记复核通过。登记受影响 Evidence/大纲/脚本/导出 ID，人工安排新版本，不替换旧成果。自动传播属于第三轮。
6. 验收新成果后由项目负责人选择使用版本；旧结果和复核映射继续保留。需要撤销时切回旧成果引用，不删除重算审计材料。

当前 UI 不保证提供所有版本关联字段，映射表须独立保存，不能声称系统已自动建立历史关联。
